## 📚 Sobre o Projeto

Este repositório foi criado com o objetivo de fornecer recursos educacionais e exemplos práticos para estudantes da visão computacional.
Os conteúdos aqui presentes abrangem desde conceitos básicos até técnicas mais avançadas, facilitando o aprendizado e a aplicação dos conhecimentos adquiridos.

## 🗂️ Estrutura do Repositório

A estrutura do repositório é organizada da seguinte forma:

- `AP1/`: Materiais e exercícios da primeira avaliação prática.
- `exercicios/`: Conjunto de notebooks com exercícios diversos sobre visão computacional.
